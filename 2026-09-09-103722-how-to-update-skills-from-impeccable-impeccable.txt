● Update command

  From the project root:

  npx impeccable skills check     # see if a newer version exists
  npx impeccable skills update    # pull it down and rewrite the installed skill

  Then reload Claude Code (/exit and restart, or restart the session) so the new
  SKILL.md is picked up. Other subcommands: npx impeccable skills install
  (first-time / re-install) and npx impeccable skills help (lists all
  /impeccable sub-commands from impeccable.style).
